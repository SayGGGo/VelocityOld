VELOCITY API ДОКУМЕНТАЦИЯ

Добро пожаловать в API Velocity! Наш API полностью совместим со стандартным форматом OpenAI, что позволяет использовать любые существующие SDK библиотеки для легкой интеграции наших мощных нейросетей в ваши проекты.

Внимание: Для использования API вам необходим доступ, который можно приобрести в Личном Кабинете в разделе «API». Баланс токенов для API списывается непосредственно с вашего основного баланса аккаунта.

АВТОРИЗАЦИЯ

Каждый запрос к нашему API должен содержать заголовок `Authorization` с вашим секретным API ключом (вы можете сгенерировать его в ЛК после покупки доступа к API).

Authorization: Bearer YOUR_API_KEY

ЭНДПОИНТЫ

POST /api/v1/chat/completions — Генерация ответа в чате

Основной эндпоинт для работы с текстовыми моделями. Поддерживает потоковую передачу данных (streaming).

Тело запроса (JSON)
{ "model": "deepseek-chat", "messages": [ {"role": "system", "content": "You are a helpful assistant."}, {"role": "user", "content": "Hello!"} ], "stream": false }
GET /api/v1/models — Список доступных моделей

Возвращает массив доступных на платформе языковых моделей.

ДОСТУПНЫЕ МОДЕЛИ

В зависимости от вашего уровня подписки или прав доступа вы можете использовать следующие идентификаторы моделей:

deepseek-chat Deepseek V3 (Экономичная / Умная)
claude-3-5-sonnet Claude 3.5 Sonnet (Флагманская)
gemini-1.5-pro Gemini 1.5 Pro

ПРИМЕРЫ КОДА

 curl http://127.0.0.1:7777/api/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{ "model": "deepseek-chat", "messages": [{"role": "user", "content": "Напиши стих про скорость"}], "stream": false }' 
 import openai client = openai.OpenAI( base_url="http://127.0.0.1:7777/api/v1", api_key="YOUR_API_KEY" ) response = client.chat.completions.create( model="deepseek-chat", messages=[ {"role": "user", "content": "Привет, расскажи о себе."} ], stream=False ) print(response.choices[0].message.content)
